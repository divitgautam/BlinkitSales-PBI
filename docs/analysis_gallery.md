# Analysis gallery

Twenty-nine charts from the six notebooks in `analysis/` (generated by `python analysis/_make_notebooks.py`). Style: `analysis/viz_style.py` (Blinkit green and yellow for categories, ColorBrewer YlGn for magnitudes, RdBu for variances, zero baselines on bars, intervals on inferential charts). Amounts in assumed INR. Data are close to a random generator, so most "no effect" results describe the source, not Blinkit.
